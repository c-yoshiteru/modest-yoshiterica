## Project: Sphere Turntable Horoscope
​〜 監獄の決定論から脱獄し、空間の幾何学と和音を奏でる旋回ポータル 〜
---

### 1. 開発コンセプト：直線から球体へ（主客の反転）

​従来の占星術（監獄の直線）：
平面の図形の上で「凶/吉」「注意せよ」という不安の決定論に縛られ、未来を予測しようとする受動的な視点。

​球体ターンテーブル（旋回知性）：
時間軸を可動スクラッチし、天体位相が球体内部に描く立体幾何学（結晶）と音響の和音（コード）を愛でる能動的な演奏者の視点。

​根本思想：
天体に占われるのではなく、天体（外側）と意識（内側）の反転鏡像関係（As above, so below）を手元でスクラッチして空間の重力をズラす。

### ​2. 4つのコア・エレメント（システム構造）

>[ 天体位相 (規則) ] × [ 内部幾何学 (視覚) ] × [ ターンテーブル (操作) ] × [ ドローン音響 (聴覚) ]

① 旋回盤（ターンテーブル・操作系）
​スクラッチ & ピッチシフト：
時間軸（過去・現在・未来）を指先で自由自在に滑らせる。
​時間操作（CUE / 早送り / 巻き戻し）：
冥王星や海王星など、超長周期の天体運動をスピードアップさせ、内部幾何学がうねるモーションとしてダイナミックに可視化する。

​② 内部の立体幾何学（ビジュアル系）
​天体アスペクトの結晶化：
天体同士の角度干渉（トライン、スクエア等）を計算し、透明な球体の「中心」に正多面体（キューブ、正十二面体など）をリアルタイム結像。

​トランスフォーム：
旋回盤を回して位相をズラすと、内部の多面体が「カシャコン」と滑らかに別の幾何学構造へと変形・展開する。

​③ 音響ドローン & 12音階（サウンド系）
​円周（五度圏 / Circle of Fifths）：
12星座の配置を「五度圏」に割り当て、調和的な対立・引き合いの幾何学を音に変換。

​各天体の役割（サウンド・アーキテクチャ）：

​トランスサタニアン（冥王星・海王星・天王星）： 空間の根本を決定づける超低周波のサイン波・ベースラインドローン。

​社会天体（土星・木星）： 和音（コード・パッド）の広がりとフィルター（倍音制限/開放）。

​個人天体（太陽・月・水星・金星・火星）： 太陽（核となる純正律音）、月（五度圏を駆け巡るアルペジオ・シーケンサー）、火星（リズム・アタック）。

### ​3. アプリケーション体験（ユーザーフロー）

​立ち上げ（グラウンディング）：
背景放射のような重厚なベースドローン（持続音）が空間に満ち、球体中心に現在の宇宙の立体幾何学が浮遊している。

​スクラッチ（時間の飛躍）：
球体をキュキュッと擦ると、時間が高速で前後し、低音が滑空（ピッチフォール）しながら内部の光の結晶が蠢く。

​結像（純正律の共鳴）：
完璧なアスペクトが組み上がった瞬間、内部の幾何学がソリッドに完成し、ドローンとアルペジオが完璧な和音（ハーモニー）となって響き渡る。

### ​4. 推奨技術スタック（実装アイデア）
​フロントエンド： HTML5 / JavaScript (ES6+)
​3D描画ライブラリ： Three.js（球体シェーダー、多面体の頂点データ演算とリアルタイム描画）

​音響・合成エンジン： Web Audio API / Tone.js（リアルタイムFM合成、ドローン・オシレーター、五度圏アルペジオ）

​UI/操作： Pointer Events / Touch Events（タッチパネル・スクラッチ操作）

​メモ：
「当たる／外れる」の二元論をポイと置いといて、
ただこのポータルを回して「今の空間のコード（和音）」を鳴らして遊ぶ。
