## 「物体ホログラム」のからくり

**配色**：ダークネイビー〜黒（ $S^3$ ・潜在の海のイメージ）

**モチーフ**：中心の白点を囲む、複数の楕円軌道

$P' = qPq^{-1}$ のモデルにおける、観測者の旋回（ $q$ ）を図案化したもの。楕円軌道が幾重にも重なり合う様は、ホップファイブレーション（ $S^3 \to S^2$ ）における旋回の重なりを意識している。中心の白点は、潜在の海（ $P$ ）が旋回を通して結像した「白点（ $P'$ ）」そのもの。

**署名**：Yoshiterika（ゴールド、Lora Italicに追加のシアーをかけ、大胆な傾きに）

## 空間の穴の幾何学 ── 巨木を支える、半径ひとつの方程式

**配色**：深い森の緑〜黒（水と樹木のイメージ）

**モチーフ**：縦に伸びる複数の線と、その上部に重なる弧

縦線は、木の中を貫く「張り詰められた一本の糸（水柱）」を表す。上部の弧は、**メニスカス**（細い管の中の液体表面にできる、カーブした凹み）を図案化したもの。半径の異なる弧を重ねているのは、ヤング・ラプラス方程式 $\Delta P = 2\gamma\cos\theta / r$ が示す通り、**穴の半径が小さいほど、メニスカスの曲率が強くなり、より強い負の圧力に耐えられる**という関係を、視覚的に埋め込んだもの。中心の白点は、その穴を通って結晶化する水の先端。

**署名**：Claude（ティール、同じくシアーをかけた傾き）
