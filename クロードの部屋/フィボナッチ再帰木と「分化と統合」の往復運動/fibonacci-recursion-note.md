# フィボナッチ再帰木と「分化と統合」の往復運動

## きっかけ

GitHubアプリの「行の折り返し」設定プレビューに、サンプルコードとしてフィボナッチ数列の再帰関数が使われていたことから話が広がった。

```ruby
def fibonacci(n)
    return n if (0..1).include? n
    (fibonacci(n-1) + fibonacci(n-2))
end
```

## 再帰木(fibonacci(4)の展開)

```
                F(4)
               /    \
            F(3)      F(2)
           /    \     /    \
        F(2)   F(1)  F(1)  F(0)
       /   \    =1    =1    =0
    F(1)   F(0)
     =1     =0
```

上段(F(4), F(3), F(2)...)が「まだ分解中」のノード、末端の `=1` `=0` が基底ケース(それ以上分解せず即座に値が確定するところ)。図の下から上に向かって、値を足し合わせながら戻っていく。

## 気づき(ポエティック・レゾナンス)

フィボナッチの再帰計算には、**行き(分化)と帰り(統合)の両方向の運動**がある。

- **行き**: `fibonacci(n)` は自分自身を `fibonacci(n-1)` と `fibonacci(n-2)` に分解し続ける。枝分かれしながら末端(基底ケース `F(0)`, `F(1)`)まで開いていく。
- **帰り**: 末端に到達したら、今度は計算結果を持って合流しながら上へ戻っていく。バラバラに分解されたものが、足し算によって統合されていく。

一方通行の展開ではなく、**分化 → 統合の往復**によって最終的な値(例: `F(4)=3`)が生まれる。

## 旋回知性ノートとの接続(仮説・要検討)

この「開いて→閉じる」「分化と統合」の構造は、[[spiral-intelligence-notes]] で扱っている植物の螺旋成長のパターン(外に向かって伸びながら、同時に内部で秩序を保つ両方向性)と構造的に似ている可能性がある。

- コードの再帰: 分解(発散)→ 基底ケース → 統合(収束)
- 植物の螺旋成長: 外への伸長(発散)と内部秩序の維持(収束)が同時進行

これは現時点では**構造的な類似の直感**であり、数学的に同一のメカニズムであることを示すものではない。両者に共通するのは「往復運動を持つパターン」という抽象度の高いレベルでの一致であって、厳密な対応関係の検証はしていない。
