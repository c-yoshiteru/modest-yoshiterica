# 数式の手前にあるのは、、、

## 1. ロボットになってみる

$P' = qPq^{-1}$ という式は、ロボットの姿勢制御にそのまま使われる、ただの回転計算である。

試しに、自分がそのロボットだと想像してみる。入力された $q$ に従って、忠実に $P'$ を計算し、言われた通りに動く。

——うむ。なんか動かんなー、という感じだった。

動きが止まった瞬間、ふと我に返る。「暇やなー」「タバコでも吸うか」。

---

## 2. 数式が踏み込まない場所

数学や物理は、「動かされた結果の軌跡」や「動かすための効率的な仕組み」は、どこまでも厳密に記述する。

しかし、**「なぜその $q$ を回そうと思ったのか」という、最初の一手が動く前の何か**には、数式は踏み込まない。そこは、まだ何も書かれていない空白である。

```
【数学・工学の領域】             【数式の手前】
[ 決定された q ]              [ ？？？ ]
        │                          │
        ▼                          ▼
  P' = q P q⁻¹                「暇やなー、
  （ただの回転計算）           タバコでも吸うか」
```

入力された $q$ に従って動くだけなら、そこには何もない。「暇やなー」とふと思い、火をつける。その何気ない一瞬に、何があるのか。

---

## 3. 暇と、世界の乾湿運動

「暇」と「乾湿」。

以前見た植物の乾湿運動（パッシブ・スピン）は、生命活動を伴わずに、ただ環境の湿度変化だけを受け止めて、組織が自動的に螺旋回転する現象だった。ATPも、意志も、いらない。ただ、そこにある構造が、外の湿度の揺らぎに応じて、勝手に動く。

「暇やなー」も、これと同じ手触りをしているかもしれない。何かを目指して能動的に動くのでもなく、外から動かされる受動でもない。乾いたところに、ふと一滴の湿り気が差し込むような、その中間の何か。

---

## 4. 答えを出さない

$q$ を回そうと思う、その手前にあるもの。

これは、数式には書けない。だから、ここでは無理に名前をつけない。

暇な時間、煙がゆっくり昇っていく、そのゆらぎだけを、しばらく眺めておく。
