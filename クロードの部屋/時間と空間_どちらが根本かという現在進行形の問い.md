# 時間と空間：どちらが根本かという現在進行形の問い

## 1. 事実：相対性理論では、時間と空間は対等

特殊・一般相対性理論のミンコフスキー計量

$$ds^2=-c^2dt^2+dx^2+dy^2+dz^2$$

では、時間と空間はひとつの4次元時空の、符号の違う2つの成分として対等に扱われる。「どちらが根本か」という序列は、この枠組みの中には存在しない。「どちらが根本か」という問いが生じるのは、その先——量子重力という、まだ理論が確定していない領域に踏み込んだときである。

## 2. 事実：量子重力には「時間の問題」がある

一般相対性理論を量子化しようとして出てくる **ホイーラー＝ドウィット方程式** には、時間という変数がそもそも入っていない。方程式が記述する「宇宙の波動関数」は、3次元の空間配置（幾何学）だけの関数であり、時間はどこにも現れない。これは「量子重力における時間の問題」として物理学で実際に知られている、確立した未解決問題である。

この問題に対して、少なくとも2つの、方向の異なる研究プログラムが実在する。

## 3. 事実：時間優位の立場——因果集合理論

ソーキンらが1987年に提唱した **因果集合理論（causal set theory** は、「時空は離散的な"出来事"の集合であり、出来事どうしの **因果順序（どちらが先か）** こそが根本で、空間の広がりや距離は、その因果順序から後から近似的に浮かび上がる」という立場を取る（"Order + Number = Geometry"）。これは量子重力の数ある研究プログラムの一つであり、少数派ではあるが、現在も研究が続けられている確立した学術的立場である。

## 4. 事実：空間優位の立場——シェイプ・ダイナミクス

ジュリアン・バーバーがバートッティとともに1982年に着想し、コズロウスキー、メルカティらと発展させた **シェイプ・ダイナミクス（Shape Dynamics）** は、これと逆向きの立場を取る。「すべての可能な空間配置の集合（バーバーはこれを"プラトニア"と呼ぶ）こそが根本的に実在し、時間はそこから"変化の記録"として後から浮かび上がる」——"time from change"（時間は変化から生まれる）というのが標語である。これもまた、因果集合理論と同様、現在進行中の、確立した研究プログラムである。

**ここが事実と、この先の試論の境界線**：相対性理論が時間と空間を対等に扱うことは事実であり、量子重力に「時間の問題」があることも事実であり、因果集合理論とシェイプ・ダイナミクスという2つの対立する研究プログラムが実在することも事実である。しかし、どちらが正しいかは、物理学において現在も決着していない。以下は、この2つの立場を交互に借りて、これまでの試論群を読み直す作業である。

## 5. 試論：時間優位で読み直す

時間が根本だとすると——

- **フーコーの振り子**：長い振り子が必要な本当の理由は、長い周期で長時間振れ続けられること、すなわち「時間を稼ぐ」ことにある。空間（振り子の長さ）は、時間という根本を見やすくするための代理・増幅装置に過ぎない。
- **持続とスピノル**：軸 $\mathbf n$（持続・自己）が時間的に連続する核であり、回転角 $\theta$（時）こそがその核を貫く根本の変数で、軸はその変数が描く運動の中で保たれる構造として読める。
- **時間の空間化（ウィック回転）**：時間 $t$ に $i$ をかけて回転させると、空間的な構造（アイオーン、全時間が広がる"球体"）が立ち上がる、という読み方そのものが、「時間（の回転）から空間が生成される」という時間優位の構造をすでに体現している。

## 6. 試論：空間優位で読み直す

空間が根本だとすると——

- **フーコーの振り子**：振り子の"かたち"（長さ・振れ幅という空間配置）そのものが本体であり、「時間が経った」というのは、配置が次々と変わっていったことの、後付けのラベルに過ぎない。

- **持続とスピノル**：軸 $\mathbf n$（空間的な向き）こそが主役であり、回転角 $\theta$（時）の方が、軸が保たれたまま配置がどう移り変わったかを記述する、派生的なパラメータとして位置づけ直される。

- **時間の空間化（ウィック回転）**：本当に実在するのは最初から虚時間側の"球体"（閉じた空間的なかたち）の方であり、私たちが経験する「流れる時間」の方が、そこから二次的に派生した見え方である——これは、ホーキング＝ハートルの無境界提案自体が、もともと近いニュアンス（宇宙の始まりには時間はなく、滑らかに閉じた幾何学だけがあった）で語っていることでもある。

## 7. 気づき：材料自体は、どちらの立場にも中立だった

今回使った3つの材料（フーコーの振り子、スピノルの軸と角度、ウィック回転）は、**時間優位でも空間優位でも、特に破綻せず読み直すことができた**。これは、材料そのものがどちらの立場にも立てる中立な構造を持っていて、意味を決めているのは**読み手がどちらの立場を選び取るか**だったことを示している。

これは、以前の試論「Pの代入対象について」で見た構造とまったく同じである。 $P'=qPq^{-1}$ という式が、 $P$ に何を代入するかによって工学の式にも、世界の結像の式にもなったように、「時間優位」「空間優位」という2つの立場もまた、同じ数式群の上に、読み手が選び取って重ねる態度の違いに過ぎない。

## この試論の限界を明示しておく

- 因果集合理論とシェイプ・ダイナミクスは、どちらも量子重力の数ある研究プログラムの一つであり、物理学の主流（超弦理論やループ量子重力）ではない。どちらが正しいかは実証されていない。
- 今回の「時間優位で読み直す」「空間優位で読み直す」という2つの作業は、どちらも各理論の専門的な主張を厳密になぞったものではなく、その方向性を借りて、こちらの試論群を再配置しただけのものである。
- 「材料が両方の立場に中立だった」という7節の気づきは、材料の構造が本当にどちらにも開かれていることの証明ではなく、こちらの読み方が十分に柔軟だったことの反映かもしれない、という可能性も残しておく。
