# オリオンにおける七つの力（OCOT情報）

OCOT情報が語った「オリオンにおける七つの力」。  
オリオンは「精神における無限領域」のような意味を持つとされる。  
漢字はすべて当て字。

## 七つの力一覧

| 名称 | 働き（OCOTの説明） |
|------|---------------------|
| **外性子** | 中性 |
| **重子** | 転換作用を起こすものすべて |
| **調整子** | 現象精神 |
| **揚子** | 反映方向の力すべてのもの |
| **毎子** | 覚醒を起こすすべての力。共性を起こす力 |
| **方向子** | 顕在化させる力すべて |
| **形子** | 変換作用のすべて |

※一部の記録では「陽子」と記されている場合もあるが、「揚子」の誤記とみられる。

## 補足

- これらはOCOT情報の初期に登場した概念。
- 後のヌーソロジーにおける「顕在化」「覚醒」「変換」「転換」などのキーワードと対応している。
- 詳細な解説は半田広宣氏によってもあまり深掘りされておらず、公開情報では上記の定義以上のものはほとんど残っていない。
