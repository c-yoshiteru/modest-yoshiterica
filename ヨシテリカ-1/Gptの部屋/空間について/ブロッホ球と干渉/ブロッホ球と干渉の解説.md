## 0. この図で見ようとしていること

3行でまとめるとこう。

1. 矢印が**2本**ある（それぞれが複素数）。
2. 2本を足すと、**強め合ったり、打ち消し合ったり**する（これが干渉）。
3. 2本の「比」だけを取り出すと、**球の上の1点**（向き）になる。しかも、干渉の強さは、その点の**影**として読める。

---

## 1. 事実：複素数は「長さと角度を持つ矢印」

複素数は、平面上の矢印として描ける。

- **長さ**：振幅（どれくらい大きいか）
- **角度**：位相（どこまで回っているか）

この図では、矢印が2本あって、**z₁**（緑）と **z₂**（紫）と呼ぶ。2本の長さの二乗を足すと、1になるように揃えてある。

$$|z_1|^2 + |z_2|^2 = 1$$

長さは、θ という1つのスライダーで決まる。

$$|z_1| = \cos\frac{\theta}{2}, \qquad |z_2| = \sin\frac{\theta}{2}$$

| θ | z₁ の長さ | z₂ の長さ |
|---|---|---|
| 0° | 1 | 0 |
| 90° | 約0.71 | 約0.71（同じ） |
| 180° | 0 | 1 |

θ は「配分」。θ = 90° は、2本の長さが等しい状態。

---

## 2. 事実：2本の足し算が「干渉」

矢印を足すには、**1本の頭に、もう1本のしっぽを繋ぐ**。原点から最後の頭までが、合成の矢印。

2本の角度の差を **φ**（位相差）と呼ぶ。合成の長さの二乗（＝強さ）は、

$$|z_1 + z_2|^2 = |z_1|^2 + |z_2|^2 + \underbrace{2|z_1||z_2|\cos\varphi}_{\text{干渉項}}$$

最初の2つは、各矢印の「単独の強さ」。3つ目の**干渉項**だけが、2本の関係（角度の差）に依存する。

| φ | cos φ | 干渉項 | 何が起きるか |
|---|---|---|---|
| 0°（同じ向き） | +1 | 最大の正 | 強め合う |
| 90° | 0 | 0 | 単独の強さの足し算のまま |
| **180°（π、正反対）** | **−1** | **最大の負** | **打ち消し合う** |

2本の長さが等しいとき（θ = 90°）、φ = 180° で合成は**ちょうどゼロ**になる。長さが違うときは、完全には消えず、**大きいほうの残り**だけが見える。

> 試してみる：[interference-pi.html](interference-pi.html) で「π にする」を押し、次に配分スライダーをずらす。

## 3. 事実：共通の位相は見えない

2本の矢印を**同時に、同じ角度だけ**回してみる（この角度を γ と呼ぶ）。

- 2本の角度の差（φ）は変わらない。
- したがって、足し算の結果の**強さ**も変わらない。合成の矢印は回るが、長さは同じ。

つまり、**2本に共通の回転は、強さには現れない**。見えるのは、2本の間の**差**だけ。これは量子力学で「全体位相は観測にかからない」と言われる事実に当たる。

> 試してみる：[bloch-sphere.html](bloch-sphere.html) の再生ボタンで γ を回す。下の矢印は2本とも回るが、球の点は動かない。

---

## 4. 事実：2本の矢印を、球の上の1点にまとめる

ここから球が出てくる。2本の矢印のうち、**共通の回転（γ）を取り除いた残り**は、2つの数で決まる。

- θ（長さの配分）
- φ（角度の差）

この2つを、**球の緯度と経度**として使うと、球の上の1点が決まる。これが**ブロッホ球**。

| 球の位置 | θ | 意味 |
|---|---|---|
| 北極（\|0⟩） | 0° | z₁ だけがある |
| 南極（\|1⟩） | 180° | z₂ だけがある |
| 赤道 | 90° | 2本の長さが等しい |
| 赤道の上を回る | φ を動かす | 2本の角度の差が変わる |

点の座標は、

$$n_x = \sin\theta\cos\varphi,\quad n_y = \sin\theta\sin\varphi,\quad n_z = \cos\theta$$

**γ は、この式のどこにも出てこない**。だから γ を回しても、球の点は動かない。

### なぜ θ ではなく θ/2 なのか

矢印の長さは cos(θ/2)、sin(θ/2) と**半分の角度**で決まる。球の上で θ を 0° から 180°（北極から南極）まで動かすと、矢印の組は (1, 0) から (0, 1) まで、90° ぶんしか動かない。球の上の動きの半分が、矢印の上の動き。

ちなみに θ を 360° まで回して球の上を1周すると、矢印の組は (−1, 0) になり、**符号が反転**する。元に戻るには2周が必要（スピノルの 4π 周期性と同じ形。ここは名前だけ置いておく）。

## 5. 事実：干渉の強さは、球の「影」になる

2節の干渉の式に、1節の長さ（cos と sin）を入れる。

$$|z_1+z_2|^2 = \cos^2\tfrac{\theta}{2} + \sin^2\tfrac{\theta}{2} + 2\cos\tfrac{\theta}{2}\sin\tfrac{\theta}{2}\cos\varphi$$

最初の2項は足すと 1 になる。3つ目は、倍角の公式（2 cos(θ/2) sin(θ/2) = sinθ）で、

$$|z_1+z_2|^2 = 1 + \sin\theta\cos\varphi = \mathbf{1 + n_x}$$

**合成の強さは、球の点の x 座標（nₓ）に 1 を足したもの**。つまり、球の点から x 軸へ垂らした影の位置が、そのまま干渉の強さになる。

| 球の点 | nₓ | 合成の強さ |
|---|---|---|
| +x の端 | +1 | 2（最大、強め合う） |
| x = 0 の面上 | 0 | 1 |
| −x の端 | −1 | **0（完全に打ち消す）** |

φ = 180°、θ = 90° のとき、点は −x の端に来る。2本の矢印は一直線に正反対を向いて、打ち消し合う。

> 試してみる：[bloch-interference.html](bloch-interference.html) で、球の点から x 軸へ垂れる点線（赤い輪）の位置が、右下のグラフの点と連動して動くのを見る。

## 6. 試論：見えているのは「影」

ここから先は、1〜5の事実の上に重ねた解釈である。

球の上の点そのものは、直接は見えない。測れるのは、**ある軸に落とした影**（この図では x 軸）で、それが干渉の強さとして現れる。別の軸で測れば、別の影が見える。点は1つで、**どの軸で測るか**によって、見える影が変わる。

また、2本の矢印のうち、**共通の回転は影にも現れない**。見えるのは、2本の間の差だけ。「見えるもの」と「見えないもの」の境界が、**共通の位相**のところに引かれている、と読むこともできる。

向かい合う（φ = 180°）関係が、干渉では「打ち消し」、球では「正反対の点」になる。同じ −1 が、2つの顔で現れている。

（前のシリーズで書いた「他者との干渉」「共通の位相は見えない」の、数学的な骨組みを見える形にしたもの、という位置づけ。ここではこれ以上は繋げない。）

## 7. 用語解説

| 用語 | 意味 |
|---|---|
| **複素数** | 長さと角度を持つ数。平面上の矢印として描ける。 |
| **振幅** | 矢印の長さ。 |
| **位相** | 矢印の角度。 |
| **位相差（φ）** | 2本の矢印の角度の差。 |
| **全体位相（γ）** | 2本に共通の角度。足し算の強さには現れない。 |
| **干渉** | 2つの波（矢印）を足したとき、強め合ったり打ち消し合ったりすること。 |
| **干渉項** | 合成の強さのうち、2本の角度の差に依存する部分。 |
| **ブロッホ球** | 2つの複素数（2準位の状態）を、球の上の1点で表す図。 |
| **2準位系** | 取りうる状態が2つ （\|0⟩） と （\|1⟩） の系。スピン1/2や、2つの光路など。 |
| （\|0⟩）（\|1⟩） | 2つの基本の状態。球の北極と南極。 |
| **射影（影）** | 点を1本の軸に垂直に落とした位置。 |

---

## この解説の限界を明示しておく

- ここで描いた「2本の矢印」は、**2準位系の状態**（複素数2つの組）の図で、普通の波の足し算とは、数学は同じでも対象が違う。
- 干渉の強さが 1 + nₓ になるのは、**x 軸方向で測る**ときの話。別の軸なら、y や z 成分が現れる。
- 完全に打ち消し合う（強さ 0）には、2つの波の**振幅が等しく**、**位相が安定している**（コヒーレント）必要がある。実際の実験では、完全な 0 にはならない。
- 試論の節で書いた「見えるものと見えないものの境界」は、構造の相似を指摘したもので、観測や意識の理論ではない。
