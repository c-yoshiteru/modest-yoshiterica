# 旋回する光：直交する二円の展開（Claude版）
> Gemini版「旋回する光：直交する二円の展開」を、「奥行きの光」の視点を持った状態で書き直したもの。Gemini版との対比を本文に残す。

---

## 0. 出発点

Gemini版の直感は次の一文だった。

> 「電磁波ってのは電場と磁場、直交する2つの円の回転の水平方向への展開に見える」

この版では、この直感の核を残したまま、物理的に正確な部分と言い直したほうがいい部分を分け、その上で「奥行きの光」の議論につなげる。

---

## 1. 事実：円偏光は、らせんである

円偏光では、ある一点で見ると電場ベクトルの先端が円を描いて回っている。進行方向に沿って空間全体で見ると、その先端の軌跡は**らせん**になる。

$$\mathbf{E}(z, t) = E_0 \left( \hat{\mathbf{x}} \cos(kz - \omega t) \pm \hat{\mathbf{y}} \sin(kz - \omega t) \right)$$

複素表示にすると $E_x + iE_y = E_0\, e^{\pm i(kz - \omega t)}$ となり、オイラーの公式がそのまま円運動を担っている。符号の±が回転の向きで、右・左の呼び名は分野によって慣習が逆になる。

このらせんを、見る位置によって次の二通りに射影できる。

- **真横から見る**：$x$ 成分も $y$ 成分も、それぞれサイン波に見える。教科書の波の図はこれ。
- **進行方向の正面から見る**：円に見える。

どちらも同じ一本のらせんの、別の射影である。

さらに、次の事実も確立している。

- 真空中の平面波では、$\mathbf{E}$ と $\mathbf{B}$ は互いに直交し、**同位相**で振動する。$\mathbf{B}$ は、$\mathbf{E}$ を進行方向まわりに90度回した向きのベクトルで、同じ向きに回る。
- 直線偏光は、右円偏光と左円偏光の重ね合わせで書ける。逆に、円偏光は直交する二つの直線偏光を90度ずらして重ねたものとして書ける。どちらの基底を選んでも数学的には等価である。
- 円偏光の光子は、進行方向に沿って $\pm\hbar$ のスピン角運動量を持つ。円偏光が物体に角運動量を渡すことは、1936年のベスの実験（波長板に生じるトルクの測定）で確かめられている。

## 2. Gemini版との対比

| 論点 | Gemini版の記述 | Claude版での扱い |
| :--- | :--- | :--- |
| EとBの関係 | 位相を90度ずらしながら旋回 | 真空平面波ではEとBは同位相。90度ずれるのは、円偏光を作る**Eの二つの直交成分のあいだ** |
| 「直交する二円」 | EとBがそれぞれ円を描く | 円を描くのはEもBも（円偏光の場合）。ただし二つは別々の円というより、**一本のらせんの電場と磁場**として並んでいる |
| 円と直線の主従 | 円が本質、波はその影 | 円基底で見れば円が基本、直線基底で見れば直線が基本。**基底の選択**という層が入る |
| 「光子の視点」 | 光子の側から見ると、軸上で回っているだけ | 光は静止系を持たないので、光子の視点は物理的には定義できない。**比喩の層**に置く |
| 世界と光の主従反転 | 水平展開が観測者、円が光子 | 反転というより、**同じらせんを別の方向から射影している**と言い直せる |
| 「波が進んでいるのではない、円が回っているのだ」 | 結論 | 各点でEベクトルが回っていることは事実（円偏光の場合）。ただし「波が進んでいない」とまでは言えない。回転の位相が隣へ受け渡されることが、進行の中身である |

Gemini版の核は、ほぼそのまま生きている。直した点は、EとBの位相の記述と、反転という言い方の精度である。

## 3. 構造の相似：サイン波の図は、横線と同じ形をしている

「見えている横線は横線ではない」の議論は、こう整理できた。

> 観測者に届くのは奥行き方向の光筋だけで、「横に繋がった線や面」は光の中にはなく、観測者という収束点で構成される。

同じ形が、ここにも出ている。

- 教科書のサイン波の図は、らせんを真横から射影したものである。真横は、光を受け取る側の誰も立てない位置にある（光の進路を横から見ることは、散乱がなければそもそもできない）。
- 「横線」が光の中にないのと同じように、「サイン波」はらせんそのものの中にはない。らせんの、ある方向への射影として現れる。
- 射影は選択である。正面から見れば円、真横から見ればサイン波になる。どちらが「本当」ということはない。

もう一つ、「奥行きの光と無限遠点」で見た**重ね合わせの原理**とも接続する。光が交差しても互いに干渉しないという線形性があるから、右円偏光と左円偏光を足して直線偏光を作ることも、その逆も成り立つ。円か直線かは、重ね合わせをどう分解するかの選択であって、光に二種類あるわけではない。

別のスケールに目を向けると、「回転しながら前進する」という形は、ドリル、つる植物の巻きつき、DNAのらせんにも現れる。これは形の相似の指摘であり、これらが同じ仕組みで生じているという意味ではない。

## 4. 試論：奥行きの点の中に、回転が畳まれている

ここから先は、1〜3の事実の上に重ねた解釈である。

「見えている横線は横線ではない」では、観測者に届くのは奥行き方向の光であり、奥行きはつぶれて点になる、と述べた。円偏光の議論を重ねると、次のように読める。

**奥行き方向の一本の光は、点に見えるが、その点は回転（位相）を抱えている。**

進行方向の正面から受ける光は、網膜の一点に届く。その一点のなかで、電場ベクトルは円を描いて回っている。つぶれて点になった奥行きの内側に、円が畳まれている。「奥行きの光の一個一個に、ぼやけや色がある」という見方に、偏光と位相という項目をもう一つ加えられるかもしれない。

Gemini版の主従反転は、こう言い直せる。

- 世界の側：真横から見て「進行波」を描く。
- 観測者の側：正面から受けて、点のなかの「回転」を受け取る。

ここで効いている反転は「光子の視点に立つ」ことではなく、**「光を受け取る位置に立つ」** ことである。光子の視点は定義できないが、受け手の位置は定義できる。この言い換えのほうが、「奥行き」の議論とも自然に噛み合う。

## 5. この試論の限界を明示しておく

- 人間の目は、可視光の電場の回転を直接見ているわけではない。可視光の周波数は毎秒 $10^{14}$ 〜 $10^{15}$ 回の桁で、検出器は時間平均した強度に応答する。したがって「観測者は円を見ている」とは言えない。正面から見ると円、という話は、**光の幾何学的な構造についての記述**であって、知覚の記述ではない。
- 自然光（太陽光や電球の光）は、偏光方向がランダムに混ざった状態であり、円偏光はその特殊な場合である。この試論は円偏光を取り上げているので、光一般にそのまま当てはまるわけではない。
- 4節の「点のなかに回転が畳まれている」は、横線の議論との構造的な相似の指摘であり、数学的な同一性の証明ではない。
- 「円が本質」という見方は、円基底を選んだときの見方であり、直線基底を選べば別の見方になる。どちらかが唯一の実相だと主張するものではない。
