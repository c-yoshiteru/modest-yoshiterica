# iの旋回：3次元の回転から4次元への跳躍

```
[ 実軸：3次元空間（直線・面・箱） ]
        │
        │ ← 90度回転（× i）
        ▼
[ 虚軸：4次元方向（意識・全存在・球体） ]
```

## 1. 3次元の回転と、4次元への「iの旋回」の違い

**3次元内の回転（実数軸の運動）**
- 幾何学： 空間の中にある「オブジェクト（物）」が位置を変える運動。
- 視点： 観測者は箱の外／内側の固定された点に留まったまま。
- 数式イメージ： 2次元や3次元の回転行列（x, y, z の再配置）。

**4次元への旋回（虚軸 $i$ を経由する反転）**
- 幾何学： 3次元空間そのものが「軸」となり、空間全体が90度ひっくり返る運動。
- 視点： 観測している「私（点）」と観測される「世界（全存在）」が交差して入れ替わる。
- 数式：

$$1 \xrightarrow{\times i} i \xrightarrow{\times i} -1$$

  1（見ている自分）に $i$（90度の視点跳躍）をかけると、世界が反転して $-1$（世界から見られている自分）になる。

## 2. 物理学との接点：複素空間とローレンツ変換

物理の世界でも、私たちが生きる「4次元時空（3次元空間＋1次元時間）」を扱うとき、この $i$ の旋回が本質的な役割を果たしている。

**ミンコフスキー空間と虚数時間 $ict$**
- 物理学では、時間軸 $t$ に光速 $c$ と虚数 $i$ をかけた $ict$ を使うことで、時間と空間を同一の幾何学として扱える（ミンコフスキー時空）。
- 時間という「目に見えない奥行き」は、3次元空間に対して **「 $i$ の角度で直交している次元」** なんだ。

**オイラーの公式と波の表現**

$$e^{i\theta} = \cos\theta + i\sin\theta$$

- 量子力学において、すべての物質や光（全存在）は「波（波動関数）」として記述される。
- 物質が「シュワーっと存在している（波動している）」のは、実数（目に見える状態）と虚数（潜伏している状態）の間を、位相 $\theta$ が絶え間なく **「複素平面上で回転（旋回）し続けているから」** に他ならない。

## 3. 人間的体感：意識の反転ダイナミクス

| 段階 | 幾何・物理のState | 人間の体験・感覚 |
|---|---|---|
| 0度 (1) | 実数軸（3次元） | 目の前の景色を「自分」が一直線の視線で見ている状態。（3次元に立つ） |
| 90度 (i) | 虚数軸（4次元方向） | 「ハッ」と視点が脱獄する瞬間。記憶の角度を見上げる、あるいは雨や気配などの全体感。（4次元方向に立つ） |
| 180度 (-1) | 主客反転 | 「雨があなたを感じている」という真逆の反転。自分が世界に包まれている体感。 |
| 連続旋回 ( $e^{i\theta}$ ) | 波動・全存在 | 「自分＝全存在」となり、境界線が解けて「シュワー」と渦を巻く感覚。 |

## 【結び】

3次元の「直線（箱）」をどこまでも進んでも4次元には着かない。

意識の力を抜いて、視線を横に90度くるりと回す（ $\times i$ ）。

その一瞬の「旋回」によって、僕たちはいつでも全存在という4次元の球体空間の上に立っている。
