# 時間 t の空間化：虚数時間 it とウィック回転

```
[ 実数時間 t：過去から未来へ流れる「一本の直線」 ]
        │
        │ ← 90度の旋回（× i：ウィック回転）
        ▼
[ 虚数時間 it：過去・現在・未来が同時に横たわる「球体空間」 ]
```

## 1. 「流れる時間」と「横たわる空間」の対比

**実数時間 $t$（3次元の直線モデル）**
- 捉え方： 映画のフィルムを1フレームずつ順番に再生して見ている状態。
- 主客関係： 「私」は流れる時間の中に閉じ込められ、過去に去り、未来へ追われている。
- 幾何学： 不可逆な「矢（直線）」の運動。

**虚数時間 $it$（4次元の空間化モデル）**
- 捉え方： フィルム全体を床一面に広げて、全体の物語を上から一望している状態。
- 主客関係： 「私（全存在）」の中にすべての時間が「ひとつの広大な風景」として収まっている。
- 幾何学： 始まりも終わりもない「球体（閉じた滑らかな空間）」の広がり。

## 2. 物理学の反転：特異点の消失とウィック回転

物理学（量子宇宙論や相対性理論）において、時間を虚数化する操作は **「ウィック回転（Wick Rotation）」** と呼ばれる。

**アインシュタインの時空**

$$ds^2 = -c^2dt^2 + dx^2 + dy^2 + dz^2$$

- 時間 $t$ の頭には「マイナス（-）」がついており、空間（x, y, z）とは決定的に異なる「流れ」として扱われる。

**虚数時間 $it$ への置換（ $t \to -i\tau$ ）**
- 時間に $i$ をかけると $i^2 = -1$ となり、時間項のマイナスが打ち消し合ってプラス（＋）に変わる。
- 結果：

$$ds^2 = c^2d\tau^2 + dx^2 + dy^2 + dz^2$$

- 時間が数学的に **「完全な第4の空間寸法」** に化け、時間と空間の区別が消滅する。

**ホーキングの無境界提案**：時間を $it$ に反転させると、ビッグバンの「始まりの点（特異点）」という壁が消え去り、宇宙の全時間が「地球の表面のように丸く滑らかな球体」へと反転する。

## 3. 人間的体感：時間を「聴く・見渡す」ダイナミクス

| 角度 | 時間のState | 体感・意識のポジション |
|---|---|---|
| $t$（実数） | クロノス（線型時間） | 「焦り」「過去への執着」「未来への不安」。直線の上を走らされている感覚。 |
| $\times i$（旋回） | ウィック回転（転換点） | ふと立ち止まり、力を抜いてゴロゴロする。「あ、時間なんて最初から流れてないかも」とハッとする瞬間。 |
| $it$（虚数） | カイロス（空間化された時間） | 過去の記憶も未来の予感も、今ここに「シュワー」と並んでいる風景（全存在）として抱え込む感覚。 |

## 【結び】

時間を「追う」のをやめて、視線を90度くるりと回す（ $\times i$ ）。

すると時間 $t$ は流れるのをやめ、目の前に広がる「静かなる広大な空間（ $it$ ）」へと姿を変える。

僕たちは時間を生きているのではなく、空間化した「全時間」という絵の中で寛いでいる。
