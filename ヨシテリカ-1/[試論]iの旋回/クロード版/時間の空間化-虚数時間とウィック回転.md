# 時間 $t$ の空間化──虚数時間とウィック回転

## 1. 事実：ウィック回転の計算

一般相対性理論における時空間隔（符号付き計量、mostly-plus）は次のように書ける。

$$ds^2 = -c^2dt^2 + dx^2 + dy^2 + dz^2$$

ここで $t = -i\tau$（$\tau$ は実数）と置換すると $dt^2 = -d\tau^2$ となるため、

$$ds^2 = c^2d\tau^2 + dx^2 + dy^2 + dz^2$$

となり、時間項の符号が反転し、空間項と同じ符号（すべて＋）に揃う。これは「ウィック回転（Wick rotation）」と呼ばれる標準的な数学的操作であり、場の量子論の経路積分の計算や、有限温度系の統計力学（虚時間形式）で実際に使われている。

## 2. 事実：ホーキングの無境界提案

量子宇宙論において、ハートル＝ホーキングは「無境界提案（no-boundary proposal）」を提唱した。宇宙の始まりを実数時間で記述すると特異点（ビッグバン）にぶつかるが、虚数時間（ユークリッド化した時間）で記述すると、その特異点が滑らかな曲面（地球儀の北極点のように、そこだけ特別扱いする必要がない点）へと解消される、という仮説である。これは検証された確立事実ではなく、量子宇宙論における一つの理論的提案であることは明記しておく。

## 3. 表記の整理：$ict$ とウィック回転は別物

「iの旋回」の章で触れた $ict$（ミンコフスキーの座標の言い換え）と、本章のウィック回転（$t=-i\tau$）は、どちらも「時間に $i$ を掛ける」という点で似ているが、由来と用途が異なる。

| | $ict$（ミンコフスキー, 1908） | ウィック回転（$t=-i\tau$） |
|---|---|---|
| 目的 | 特殊相対論の時空間隔をユークリッド的な見た目に書く座標の言い換え | 経路積分・量子宇宙論での解析接続という計算技法 |
| 時間の扱い | 表記上の書き換えのみ。物理的な時間の流れ自体は変わらない | 実際に複素平面上で時間軸を回転させ、計算後に実時間へ戻す |

両者を安易に同一視せず、「発想は親戚だが、使われ方は別物」として扱う方が正確である。

## 4. 試論：「流れる時間」から「横たわる空間」への意識の反転

ここから先は、事実の上に重ねた試論である。

ウィック回転が「時間項の符号を空間項と揃える」という数学的操作である事実の上に、「だから過去・現在・未来がひとつの風景として横たわっている」という体感の比喩を重ねることは、物理学が要求するものではない。ウィック回転は経路積分を計算するための解析接続の技法であり、計算後は再び実時間へ戻して物理的な予言（実数の確率や振幅）を得る、というのが標準的な使い方である。「虚時間の間、宇宙は本当に空間化されている」という存在論的な主張は、無境界提案の枠内でも慎重に扱われるべき解釈上の一歩である。

「クロノス（直線的な時間の体感）」と「アイオーン（全時間が横たわる体感）」という対比は、ギリシャ哲学に由来する時間概念（クロノス／カイロス／アイオーン）を借用した比喩的枠組みであり、物理学の用語ではない。この対応づけを「物理学的事実」として提示しないよう、ここに明記しておく。

### この試論の限界を明示しておく

- ウィック回転は計算技法であり、それをもって「時間は本当は流れていない」という存在論を直接導出することはできない。
- クロノス／カイロス／アイオーンの区分は哲学的概念であり、90度・180度という回転角度への対応づけは試論固有の比喩である。
